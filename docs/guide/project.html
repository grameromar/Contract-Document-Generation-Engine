Pendientes

Nada de esto está implementado.

Decisiones tomadas

  • Números exactos: number conservará el decimal tal como lo escribe el usuario, sin pasar por float (sin perder dígitos ni caer en notación científica). Se permite quitar los ceros a la derecha.
  • Idioma de las fechas: los nombres de meses y días de date saldrán en un idioma elegible, español por defecto, en vez de depender del locale del proceso. Falta diseñar dónde se elige el idioma.

Por hacer

  • Capa web: añadir a /generate el campo de idioma de las fechas y fusionar las ramas web en main.
  • Frontend: React con TypeScript (Vite). Cargar el .tex, llamar a /parse, formulario con un control por tipo (texto, número, selector de fecha, casilla, lista), enviar a /generate, descargar el PDF y mostrar los errores.
  • Pulido del backend: Dockerfile (Tectonic más fontconfig en Debian slim).
  • Opcionales: subir la plantilla como archivo multipart, y endurecer el aislamiento de la compilación para producción.
