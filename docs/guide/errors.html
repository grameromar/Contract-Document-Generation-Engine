Core

Errores

El core lanza excepciones propias, todas hijas de LatexGenError, para que una capa externa pueda traducirlas a mensajes para el usuario sin conocer los detalles internos.

Jerarquía

Atrapar RenderError cubre todo lo que falla al convertir los valores del usuario en documento; atrapar LatexGenError cubre cualquier error del core.

Mensajes de los escapers

Son el reason de InvalidFieldValueError. {value!r} es la representación de Python del valor (con comillas si es texto).

TipoMensaje
numberExpected a numeric value, received: {value!r}
dateExpected an ISO date (YYYY-MM-DD), received: {value!r}
booleanCannot interpret value as boolean: {value!r}
enumValue '{text}' is not among the allowed options: {options}

get_escaper también lanza ValueError("No escaper available for type: …") con un tipo desconocido, pero desde el pipeline no ocurre: el parser rechaza antes esos tipos.

Errores que no son del dominio

  • Datos en vez de excepción: TectonicCompiler.compile no lanza por un error de LaTeX ni por timeout; devuelve CompileResult(ok=False). Solo generate lo convierte en CompileError. Quien use el compilador directamente debe revisar ok.
  • Otros errores de sistema: el código solo atrapa FileNotFoundError y TimeoutExpired alrededor de subprocess.run. Cualquier otro (por ejemplo, permisos o disco lleno al escribir el .tex) se propaga sin traducir.
